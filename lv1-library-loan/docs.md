# Lv.1: 図書館の貸出システム

## 要求文

> 図書館の貸出システムを作っている。本には「タイトル」「著者」「ISBN」がある。会員は本を借りることができるが、延滞中の本が1冊でもある会員は新たに借りることができない。貸出には貸出日と返却期限(貸出日から14日後)がある。

## ユビキタス言語
|言語|意味|
|---|---|
|本|貸し出す対象物。情報として「本ID」「タイトル」「著者」「ISBN」を持つ|
|本ID|本をユニークに識別する識別子|
|会員|本を借りることのできるユーザー。情報として「会員ID」「氏名」を持つ|
|会員ID|会員をユニークに識別する識別子|
|図書館が本を貸し出す/会員が本を借りる|会員が図書館から本を借りる行為。以下の制約がある<br>- 延滞中の本が１冊でもある会員は新しく本を借りることができない|
|貸出記録|本の貸出の記録|
|貸出記録ID|貸出記録をユニークに識別する識別子|
|貸出日|図書館が本を貸し出した日|
|返却期限|貸出日から14日後|
|延滞|返却期限以内に会員が本を返却しなかった状態|
|貸出ステータス|本の貸出状態。以下のいずれか<br>- 貸出中<br>- 返却済|
|会員が本を返却する|会員が借りた本を図書館へ返却する行為|



モデリング(クラス図・不変条件)は [model.md](model.md) に書く。
